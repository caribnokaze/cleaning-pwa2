# 希望シフト連携の設定

## Apps Script

1. 回答シートの閲覧権限を持つ管理用アカウントで Apps Script プロジェクトを作り、`shift/Code.gs` を配置します。
2. Script Properties に `SHIFT_SPREADSHEET_ID` と `SHIFT_GAS_SECRET` を設定します。署名鍵はこの連携専用に生成した、十分な乱数を含む32文字以上の値を使います。回答シートは現在の共有設定を維持します。
3. 管理用アカウントとして実行するウェブアプリをデプロイし、Express から Google の対話ログインなしで呼び出せる設定の `/exec` URL を取得します。この実装では GAS が署名、時刻、最近のリクエストIDを確認してからシートを読みます。Google Workspace の組織設定でこの公開範囲を選べない場合は、管理者の許可または別の認証方式への対応が必要です。
4. Express の実行環境に `SHIFT_GAS_URL` と `SHIFT_GAS_SECRET` を設定します。本番では署名鍵を保護された設定から注入してください。既存の AWS 配備スクリプトはこれらを設定しないため、本番配備に使う方式を確認し、配備のたびに設定が維持されるようにしてください。

## 回答の読み取り

- 通常は `2026-12` に対して `2026.12` タブを参照し、シートにある年月のうち新しい3か月だけを表示します。別名のタブを使う月は、Script Properties の `SHIFT_MONTH_TABS` に JSON オブジェクトで指定できます。指定できるのは月ごとに1タブです。複数のタブに分かれた月は、表示対象を決めてから設定してください。
- D列に担当者番号と氏名、E列以降に日付列がある前提です。番号がない担当者は選択肢に表示しません。同じ担当者が複数回提出した場合は、D列で一致する行のうち一番下の行を使います。
- 初回は数字、`休`、`未定`、空欄を扱います。その他の回答値がある場合はデータ取得エラーとして扱います。
- 共通ログインの利用者はすべての担当者を選べます。回答シートのメールアドレス列は読み取りません。GASからブラウザへの直接通信はありません。

設定後は、報告画面で担当者を選択して「希望シフト」を開き、選択済みの担当者が初期表示されることを確認してください。対象月を切り替えてシートと照合し、再読み込みで変更が反映されることも確認してください。
